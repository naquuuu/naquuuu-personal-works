# Recommended Personal Tech Stack

Guidelines for personal web development, tooling, and infrastructure.

---

## 1. Web & Frontend
- **HTML/CSS/JS**: Vanilla CSS / CSS Variables for lightweight, zero-build projects (e.g. `naquuuu.github.io`).
- **Frameworks (when needed)**: Vite + React or Next.js for interactive web applications.
- **Design Tokens**: Standardized CSS tokens for colors, spacing, and typography across portfolio applications.
- **Hosting**: GitHub Pages (custom domain), Cloudflare Pages, or Vercel.

---

## 2. Automation & Scripting
- **Python**: Python 3.10+ for utilities, scrapers, and data cleaning.
- **CLI Shell**: PowerShell 7+ on Windows, bash for cross-platform scripts.
- **Node.js**: LTS version for web tooling.

---

## 3. AI & Language Models
- **Provider**: Google Gemini API via Single Personal GCP Project.
- **Models**:
  - `gemini-3.8-flash` / `gemini-2.5-flash`: Fast coding, scaffolding, and iterative editing.
  - `gemini-3.1-pro`: Deep architecture design, complex refactoring, and creative writing.
- **Client Tools**: Antigravity IDE, OpenCode CLI, Python `google-genai` SDK.
